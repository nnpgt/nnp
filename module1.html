Модуль 1 — вопросы и ответы

45 вопросов по заданию «Настройка сетевой инфраструктуры»

Важно: ответы составлены по PDF, страницы 42–47. Если точное значение в задании отсутствует, это отмечено отдельно. Значения из примера конфигурации сайта не являются обязательными требованиями PDF.

1Как называется итоговый файл отчёта?

ФамилияУчастникаМодуль1 (без расширения).

2Какими должны быть снимки экрана в отчёте?

Они должны быть кадрированы так, чтобы относящаяся к заданию информация оставалась читаемой.

3Что должно быть в названии документа по каждому пункту?

Индекс пункта задания и краткое описание.

4Где сохранить итоговый отчёт?

На диске рабочего места.

5Как задаётся имя устройства?нет точного значения в PDF

По топологии, с использованием полного доменного имени (FQDN), например hq-srv.au-team.irpo.

6По какой таблице определить полное доменное имя?

По таблице 3 задания.

7Из какого диапазона брать локальные IP-адреса?

Из частного диапазона IPv4 согласно RFC 1918.

8Какой размер сети допускается для HQ-SRV (VLAN 100)?

Не более 32 адресов.

9Какой размер сети требуется для HQ-CLI (VLAN 200)?

Не менее 16 адресов.

10Какой размер сети допускается для управления (VLAN 999)?

Не более 8 адресов.

11Какая маска нужна между BR-FW и BR-RTR?нет точного значения в PDF

В рассматриваемом тексте задания (стр. 42–47) это требование не указано; точную маску по нему определить нельзя.

12Какой размер сети допускается для BR-SRV?

Не более 16 адресов.

13В какую таблицу заносить IP-адреса и шлюзы?

В таблицу 2.

14Как получает адрес интерфейс ISP, подключённый к провайдеру?

По DHCP.

15Какой маршрут настраивается на ISP для выхода в Интернет?

Маршрут по умолчанию, если он необходим.

16К какой сети подключён ISP со стороны HQ-RTR?

К сети 172.16.1.0/28.

17К какой сети подключён ISP со стороны BR-RTR?

К сети 172.16.2.0/28.

18Какую трансляцию адресов настроить на ISP?

Динамическую сетевую трансляцию портов (NAT/PAT) для HQ-RTR и BR-RTR.

19На каких серверах создать локального пользователя sshuser?

На HQ-SRV и BR-SRV. В PDF есть несогласованность: сначала упомянут remote_user, а следующая строка говорит о пароле пользователя sshuser.

20Какой пароль назначить sshuser?

P@ssw0rd.

21Какой UID назначить sshuser?

2026.

22Как запускать команды с повышенными привилегиями пользователю sshuser?

Пользователь должен иметь возможность запускать sudo без ввода пароля.

23На каких устройствах создать net_admin?

На маршрутизаторах HQ-RTR и BR-RTR.

24Какие привилегии нужны net_admin в ОС не на базе Linux?

Максимальные привилегии.

25В каком VLAN должен быть трафик HQ-SRV?

VLAN 100.

26В каком VLAN должен быть трафик HQ-CLI?

VLAN 200.

27Для чего нужен VLAN 999?

Для передачи трафика управления.

28Как маршрутизировать все VLAN на HQ-RTR?

Через один сетевой адаптер виртуальной машины или один физический порт.

29Какой порт использовать для безопасного удалённого доступа?

TCP-порт 2026.

30Кому разрешить подключение по SSH?

Только пользователю sshuser.

31Сколько попыток входа разрешить?

Не более двух.

32Какой текст должен быть в баннере SSH?

Authorized access only

33Между какими устройствами поднять IP-туннель?

Между HQ-RTR и BR-RTR.

34Какой протокол использовать для IP-туннеля?

На выбор: GRE или IP in IP.

35Какой диапазон адресов использовать для туннеля?нет точного значения в PDF

PDF не задаёт конкретный диапазон. Его выбирает участник; адреса должны быть согласованы на обоих концах туннеля. В текущем примере сайта используется 10.10.10.0/30 — это пример настройки сайта, а не обязательное значение из PDF.

36Какая маска требуется для сети туннеля?нет точного значения в PDF

В PDF точная маска не задана. В текущем примере сайта используется /30; это выбранный пример, а не прямое требование документа.

37Какой протокол динамической маршрутизации использовать?нет точного значения в PDF

Нужен протокол класса link-state на усмотрение участника; в текущем примере сайта используется OSPF.

38На каких интерфейсах разрешён протокол маршрутизации на HQ-RTR и BR-RTR?

Только на интерфейсах IP-туннеля.

39На каком интерфейсе BR-FW разрешён OSPF?нет точного значения в PDF

В рассматриваемом варианте задания на страницах 42–47 BR-FW и его интерфейсы не описаны. Ответ в документе не найден.

40Какой тип аутентификации использовать в OSPF?нет точного значения в PDF

PDF требует защитить протокол паролем, но конкретный тип аутентификации не называет. В текущем примере сайта используется message-digest (MD5).

41Какой пароль использовать для OSPF?нет точного значения в PDF

В PDF пароль не указан. В текущем примере конфигурации сайта указан P@ssw0rd; это значение примера, а не требование PDF.

42Кто является DHCP-сервером для HQ-CLI?

Маршрутизатор HQ-RTR.

43Какой DNS-сервер указать для HQ-CLI?нет точного значения в PDF

IP-адрес сервера HQ-SRV. В текущем примере сайта это 192.168.100.2; фактический адрес должен соответствовать таблице 2.

44Какой DNS-суффикс задать HQ-CLI?

au-team.irpo.

45На каких устройствах настраивать часовой пояс?

На всех устройствах, кроме виртуального коммутатора (если он используется); часовой пояс должен соответствовать месту проведения экзамена.
